# 电子作业：ZnS 与 GaN 纤锌矿结构及 XRD 对比分析报告

## 一、 构型差异分析

ZnS 和 GaN 均属于典型的 **AB 型纤锌矿结构**（六方晶系，空间群 P6_3mc）。对比两者的三维构型，主要存在以下异同：

### 1. 相同点
*   **结构类型**：两者均属于纤锌矿结构。
*   **配位方式**：每个 A 原子（Zn/Ga）被四个 B 原子（S/N）包围形成四面体，反之亦然，配位数均为 4。
*   **原子排列**：原子在晶格中均呈现 ABAB... 的密排六方堆垛顺序。

### 2. 不同点（晶格常数与键长）
*   **ZnS 晶格**：晶格常数较大（a = 0.382 nm, c = 0.626 nm）。
*   **GaN 晶格**：晶格常数较小（a = 0.319 nm, c = 0.518 nm）。
*   **差异原因**：Ga-N 键的键长比 Zn-S 键短。Ga 和 N 的原子半径均小于 Zn 和 S，导致 GaN 的晶胞体积更小，原子排列更紧密。

## 二、 XRD 图谱差异分析

根据模拟的 XRD 图谱对比（基于 Cu Kα 辐射），可以得出以下显著差异：

### 1. 峰位整体偏移
*   **现象**：GaN 的所有衍射峰（如 (100)、(002)、(101) 等）均出现在**更高的 2θ 角度**。
*   **机理**：由于 GaN 的晶格常数更小，导致晶面间距 d 更小。根据布拉格方程 2d·sinθ = λ，晶面间距 d 越小，衍射角 2θ 越大。

### 2. 峰形与相对强度
*   由于两者晶体结构相同（同为纤锌矿），其衍射峰的数量和各峰相对强度的分布趋势（例如最强峰通常为 (101) 或 (002)）非常相似。
*   但由于组成元素的原子散射因子不同（Ga 和 N 对比 Zn 和 S），各峰的具体相对强度会有细微差异。

### 3. 结论
XRD 图谱整体向左或向右的“平移”是判断晶格常数变化（如固溶体形成、应力应变或成分变化）的重要依据。晶格常数越小，XRD 衍射峰整体越向高角度偏移。
